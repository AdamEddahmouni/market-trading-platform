# Short Squeeze Glossary (Deliverable 8)

| Term | Definition | Does **not** mean |
|---|---|---|
| short sale | Sale of borrowed shares | A completed short position lifetime |
| short interest | Outstanding shares sold short and not yet covered | Daily short-sale volume |
| short float | SI as % of float | SI as % of outstanding (different denominator) |
| short-sale volume | Daily volume of short sales | Change in outstanding SI |
| days to cover | SI / average daily volume | Time until squeeze ends |
| borrow | Loan of shares to facilitate shorting | Guaranteed indefinite availability |
| lendable supply | Shares available to lend | Float |
| shares on loan | Shares currently lent | Short interest (close cousin, not identical) |
| utilization | Loaned shares / lendable supply | Short float % |
| borrow fee | Cost to borrow (annualized %) | Guaranteed squeeze trigger |
| HTB | Hard-to-borrow status | Immediate forced cover |
| recall | Lender demand to return shares | Automatic market buy order |
| market squeeze | Price rise from cover + demand feedback | Any rally |
| lender squeeze | Scarcity-driven return/reborrow stress | Identical to market squeeze |
| gamma squeeze | Dealer hedging amplification | High call volume alone |
| short covering | Purchases to close short positions | All buy volume |
| FTD | Fail-to-deliver balance | Naked short count |
| threshold security | Reg SHO threshold list status | Countdown to forced cover |
| RVOL | Volume vs typical for time of day | Guaranteed continuation |
| turnover | Volume relative to float/shares | SI change |
| effective float | Float minus closely held/illiquid stock | Reported float |
| CVD | Cumulative volume delta by aggressor side | Proof of short covering |
| aggressor | Initiator of trade (buy/sell) | Always known (often uncertain) |
| catalyst | Event invalidating or reinforcing thesis | Generic positive sentiment |
| attention | Measured interest velocity | Mention count alone |
| ignition | Onset of forcing demand against shorts | High SI |
| reflexivity | Self-reinforcing price-feedback loop | Momentum without mechanism |
| remaining fuel | Estimated uncovered forced demand left | Future return magnitude |
| exhaustion | Declining incremental squeeze pressure | Top tick certainty |

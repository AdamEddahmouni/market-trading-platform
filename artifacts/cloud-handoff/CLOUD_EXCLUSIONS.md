# Cloud Handoff Exclusions

Categories of content deliberately **not** uploaded to the private remote during the 2026-08-25 cloud handoff.

## REGENERABLE

| Path / pattern | Reason | Required for engineering | Cloud replacement |
|---|---|---|---|
| `.venv/` | Python virtual environment binaries | No (reinstall) | `bash .cursor/install-cloud-deps.sh` |
| `**/__pycache__/` | Python bytecode cache | No | Regenerated on import |
| `.pytest_cache/` | Pytest cache | No | Regenerated |
| `ui/node_modules/` | Node dependencies | No | `npm ci` in `ui/` |
| `pipelines/stock_data/.venv/` | Pipeline-local venv | No | Separate pipeline setup |
| `pipelines/stock_data/**/__pycache__/` | Pipeline bytecode | No | Regenerated |
| `build/`, `dist/`, `*.egg-info/` | Build artifacts | No | Rebuild if needed |

## SECRET

| Path / pattern | Reason | Required | Cloud replacement |

# IMP-REBASE-02 known limitations

## Current program limitations (do not block REBASE-02 acceptance)

These limitations existed before REBASE-02 and remain after it. They are
expected downstream work, not defects in the standards milestone.

- Universal Run Ledger and common attempt/disposition runtime not implemented
  (`IMP-OF-01` not started).
- Operation adapters not implemented (`IMP-OF-02`).
- End-to-end trace propagation and accepted performance baseline not
  implemented (`IMP-RT-01`).
- Cross-asset kernel consolidation incomplete (`IMP-XA-01`).
- Workflow and control registry not implemented (`IMP-OF-03`).
- Attributable AI operations runtime not implemented (`IMP-AI-01`).
- Adaptive Fabric and ADAPT runtime not implemented.
- MLflow, River, and adaptive-learning libraries not integrated.
- Benchmark gating and performance budgets not defined.
- Retention durations and legal deletion rules not specified.
- Dirty-source capsule storage format not frozen.

## REBASE-02 acceptance limitations

None.

REBASE-02 acceptance limitations apply only to unresolved deficiencies in the
standards milestone itself. All approved specification requirements were
implemented and validated.

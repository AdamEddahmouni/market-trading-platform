# IMP-REBASE-01 acceptance evidence

Disposition: `IMP_REBASE_01_COMPLETE`

IMP-REBASE-01 establishes the canonical program-documentation layer, repairs
the approved repository entry points, preserves historical and executable
authority, and binds the accepted documentation surface with deterministic
hashes. It is documentation-only and grants no provider, policy, model,
qualification, release, risk, execution, broker, or autonomous-agent authority.

## Package

- [Acceptance report](REBASE01_ACCEPTANCE_REPORT.md) — implementation identity,
  document map, migration analysis, consistency matrix, validation, and
  acceptance judgment.
- [Known limitations](REBASE01_KNOWN_LIMITATIONS.md) — program limitations
  separated from limitations of this milestone.
- [Accepted-surface hashes](REBASE01_FILE_HASHES.json) — sorted SHA-256 and byte
  length for every accepted file except the manifest itself.

The implementation contract is the
[final REBASE-01 specification](../../../docs/superpowers/specs/2026-08-27-imp-rebase-01-canonical-program-architecture-implementation-spec.md).
Historical audit evidence remains in [REBASE-00](../REBASE00/README.md).
